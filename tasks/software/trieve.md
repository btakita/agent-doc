**Trieve** is an AI search infrastructure company that provides an all-in-one API for search, retrieval-augmented generation (RAG), and recommendations.

**Key facts:**

- **Founded:** 2023 at the FUTO campus in Austin, TX (FUTO provided open-source grant funding)
- **Founders:** Nicholas Khami and Denzell Ford
- **Y Combinator:** W24 batch
- **Funding:** $3.5M Seed round (September 2024) from Root Ventures, Soma Capital, Transpose Platform Management, and YC
- **Revenue:** Hit $900K in 2024 with a 6-person team
- **Acquired:** By Mintlify (documentation platform) in July 2025, to enhance AI-powered knowledge retrieval in their docs products

**Product/Technology:**

- API platform for semantic search, chat, recommendations, and generative AI
- Features include date recency biasing, re-ranker models, sub-sentence matching
- Infrastructure combining search language models with human fine-tuning tools
- Focused on retrieval quality for RAG pipelines

**Target market:** Businesses needing AI-powered search and discovery across e-commerce, ERP, social media, and documentation platforms.

**Current status:** Post-acquisition, Trieve's technology is being integrated into Mintlify's documentation platform.
