# GH #339 shell file set for the classic package (editors/jetbrains/SPEC.md
# "Restart-free implementation generations"). Paths are relative to this file.
# An entry ending in "/" is a directory prefix; any other entry is one file.
#
# A file is shell when it matches a [shell] entry, otherwise implementation when
# it matches an [impl] entry, otherwise neither. `generateShellIdentity` hashes
# each set into `shell_digest` / `impl_digest`, and the activation receipt
# reports `shell=<shell_digest>`. A shell change always needs an IDE restart.
#
# gradle.properties is deliberately in neither set: it carries the package
# version and source digest, which change on every release.
