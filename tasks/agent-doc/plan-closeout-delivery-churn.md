# Closeout and editor-delivery churn contract

## Architecture contract

- **Invariant:** A remote delivery identity may be decoded into a local replica at most once while its visible editor projection or ACK is outstanding. Exact visible editor content is sufficient ACK proof even when disk persistence is deliberately deferred; disk-save status cannot gate the ACK. Repeated pulls of that identity coalesce into the retained projection/ACK state; they do not mutate the replica again, enqueue another EDT apply, or count as forward progress.
- **Invariant:** Closeout reports `committed` only when the authoritative response projection is durable and the session document at `HEAD` equals the proven closeout snapshot. A binary-owned compacted projection may cross the historical-response guard only with durable compaction evidence; arbitrary response-bearing drift remains fail-closed.
- **Invariant:** Commit-seam free-text cleanup is a bounded disk transaction. It performs no controller lookup while holding the document lock; ordinary editor-authoritative cleanup finishes its controller read before lock acquisition.
- **Invariant:** A baseline overlay is a cache paired with a named explicit markdown baseline, never implicit merge authority. With no baseline path, a stale `.overlay.yrs` sidecar cannot resurrect a consumed queue head.
- **Invariant:** Controller recycle invalidates a JetBrains replica registration and starts bounded re-registration. A disconnected relay cannot remain permanently idle while its document is still open.
- **Invariant:** Force-disk authorization is revalidated at the mutation boundary. If an editor relay registers or editor authority otherwise changes after authorization, the force-disk transaction aborts before projection/commit; it cannot race the relay, duplicate a response, or advance the boundary from stale content.
- **Invariant:** A timed-out preflight cannot retain document/controller work after its owner exits. Cleanup may signal another process only with same-document, command-shape, age, and orphan/owner-death proof; wrapper exit 144 after an intentional kill is cancellation evidence, not a new product failure.
- **Invariant:** Controller backpressure is a shared-capacity signal, not a retry prompt. Idle watchers use one controller-wide bounded backoff/coalescing gate, and a live-editor response already materialized by semantic response identity is retired instead of resubmitted to the merge/write path.
- **Invariant:** Release and local-install automation must produce an artifact accepted by its destination and must select a JetBrains target from explicit or runtime-proven evidence. Ambiguous targets fail with an actionable selector instead of consuming stdin implicitly.
- **Policy owners:** `CrdtReplicaManager` owns in-flight delivery identity, visible projection, ACK retention, and recycle re-registration; `agent-doc-queue-io` owns strike read/lock ordering and commit-seam disk authority; `agent-doc-write-runtime-io` owns explicit baseline selection; `agent-doc-document-realtime-io` owns the force-disk authorization scope and mutation fence while write/compact entrypoints hold that scope across response generation; `agent-doc-agent-io` owns timeout process-group cleanup/classification; `agent-doc-commit-io` plus the preflight/session-check closeout projection owns durable HEAD proof and compaction authorization; the `Makefile` owns PyPI wheel compatibility; `src/plugin.rs` owns JetBrains target discovery and selection.
- **Evidence inputs:** remote `patch_id` and `generation`, update bytes/content hash, current forwarder identity, controller instance/transport failure, pending EDT projection and retained ACK map, strike mode and disk/controller source, document-lock boundary, explicit baseline path and paired markdown/model content, force-disk authority epoch and relay count immediately before mutation, process command line/document/parent/start age, editor/disk/shadow hashes, cycle phase and response marker, snapshot/file/HEAD hashes, authoritative-compaction scope and archived exchange evidence, host wheel compatibility, explicit plugin directory and active IDE `idea.plugins.path` evidence.
- **Allowed edit surfaces:** JetBrains replica manager/forwarder lifecycle utilities and focused tests/spec; queue consume read/lock policy and focused tests; write-runtime baseline and force-disk scope entrypoints; document-realtime force-disk authority/focused tests; agent backend child-process lifecycle and focused tests; compact force-disk scope port; closeout commit, preflight/session-check proof code only if evidence requires it; plugin installer CLI/discovery/tests; Makefile release target and release documentation; generated skill/version surfaces required by a patch release.
- **Verification:** reproduce duplicate pull behavior in a deterministic replica-delivery test; prove one decode/apply and retained ACK retry; prove controller loss triggers bounded replica re-registration; prove commit-seam strike performs no controller lookup and ordinary strike reads before lock; prove absent explicit baseline ignores stale overlay; prove a relay appearing after force-disk authorization aborts without write/commit while an already-live authorization retains its explicit semantics; prove a timed-out backend process group reaps a real background descendant and records cancellation; unit-test explicit/proven/ambiguous JetBrains selection; build a `manylinux_2_17` wheel; run `make check`, editor suites, installation, and release validation.
- **Out of scope:** redesigning the controller CRDT or observable-set history, broad queue cleanup, automatic GUI restart, adopting arbitrary unsaved editor text, and unrelated working-tree changes.

## Transition table

| Surface | Current state | Evidence/event | Next state | Required effect |
| --- | --- | --- | --- | --- |
| JetBrains delivery | no in-flight identity | new peer delivery | projection pending | decode once, retain identity and ACK evidence, enqueue once |
| JetBrains delivery | projection pending | same delivery repeats | projection pending | coalesce/no-op; no decode, enqueue, or progress credit |
| JetBrains delivery | projection pending | distinct newer delivery | projection pending | merge only through the keyed projection owner and retain all unique ACK identities |
| JetBrains delivery | projection applied | exact visible-content proof, with or without disk persistence | ACK pending or settled | ACK through newest proven generation; retain on transport failure |
| JetBrains delivery | ACK pending | same delivery repeats | ACK pending | retry retained ACK before pull; do not decode again |
| JetBrains delivery | failed/stale projection | editor advanced | retry/reconcile | remove in-flight projection only after recording a bounded reconciliation request |
| JetBrains relay | registered | controller transport/instance is lost | re-registering | invalidate the old registration and retry registration with bounded backoff while the document stays open |
| idle watch | controller model reports backpressure | other sessions are polling or a publish is active | controller-wide cooldown | coalesce observation, stop issuing per-document controller reads, and retry once after bounded quiet time |
| closeout retry | response semantic cell already exists in live editor | retained capture or component merge repeats it | absorbed | retire the duplicate capture, preserve prompts, advance the boundary once, and do not submit another merge/write candidate |
| JetBrains relay | re-registering | new controller accepts registration | registered | resume delivery/ACK from the retained frontier; do not replay an already-decoded identity |
| free-text strike | commit seam | response capture present | disk transaction | acquire the document lock, read disk once, strike disk-present heads, write atomically; never query controller |
| free-text strike | ordinary editor-authoritative cleanup | controller lookup requested | content resolved | resolve before acquiring the document lock; convergence write compares against that source |
| free-text strike | disk queue empty, controller/cache head stale | phantom head observed | no-op/recovery | preserve disk, do not resurrect/strike the phantom from cache, and log stale evidence |
| baseline resolution | no explicit baseline path | stale model sidecar exists | no baseline | ignore the sidecar; do not merge or replay it |
| baseline resolution | explicit markdown baseline supplied | paired model projection matches | explicit baseline | use the paired cache with markdown as divergence backstop |
| force-disk closeout | relay absent at authorization | relay still absent at mutation fence | writing | compose once from the fenced disk/HEAD source and commit exact projection |
| force-disk closeout | relay absent at authorization | relay appears before mutation fence | blocked | abort before write/commit and retry through editor authority |
| preflight process | prior run timed out | same-document owner proven dead and process old | reaping | terminate the proven orphan, release resources, and record cancellation |
| preflight process | prior run appears slow | owner live or identity proof incomplete | preserved | never signal; report contention with actionable evidence |
| closeout | response projected | file = snapshot = HEAD | committed | persist terminal proof and report success |
| closeout | response projected | snapshot/file differ from HEAD | interrupted | preserve recovery evidence; never report committed |
| closeout | historical response differs | no authoritative compaction proof | blocked | retain the historical-patchback guard |
| closeout | historical response differs | binary-owned compaction scope plus archived-turn proof | committing | compose/commit compacted projection, then verify HEAD equality |
| JetBrains install | explicit target supplied | target is a valid plugin root | installing | use it without prompting |
| JetBrains install | no explicit target | exactly one runtime-proven active target | installing | use the proven target and print the evidence |
| JetBrains install | no explicit target | multiple or no proven targets | blocked | list candidates and require an explicit selector |
| PyPI publish | release requested | compatibility build succeeds | publishing | upload `manylinux_2_17` wheel |
| PyPI publish | compatibility build unavailable | missing Zig/toolchain or invalid tag | blocked | fail before upload with remediation |
