## Existence Lang as Executable Philosophy

Strong connection. ExPhil (Steve Phillips, executablephilosophy.org) encodes philosophical theories as programs — compute philosophical facts, enforce constraints on theories, detect inconsistencies, remove intuition from argument chains. Their examples use Python to formalize reference theories (Descriptivism vs Direct Reference) and voting systems.

**Existence Lang goes deeper.** ExPhil encodes *individual theories* in code. Existence Lang encodes the *ontological substrate itself* — the 14-term kernel (Existence → Entity → System → Domain → Scope → Context → Resolution → Focus...) that all theories and domains derive from.

### Key differences

| | ExPhil | Existence Lang |
|---|---|---|
| **Scope** | Individual theories (descriptivism, voting) | Universal ontology kernel |
| **Language** | Python (general-purpose) | Custom spec + Rust CLI + TOML ring system |
| **Goal** | Compute philosophical facts | Human-agentic coherence across all domains |
| **Extension** | Write new Python programs | Domain overlays in CLAUDE.md derive from kernel |
| **Users** | Philosophers | AI agents + humans working together |

### Why "crown jewel for human-agentic coherence"

ExPhil's insight: natural language is too ambiguous for rigorous philosophy. Existence Lang extends this: natural language is too ambiguous for *human-agent alignment*. When an agent and a human share a formal ontology:

1. **Terms have canonical definitions** — "Context" means scope applied to abstractions, not whatever the LLM's training data weighted
2. **Derivation chains are explicit** — a project's "Session" derives from kernel "project + story", traceable
3. **Ring structure controls resolution** — Ring 0 (14 universal terms) always loaded, higher rings on demand
4. **Domain overlays compose** — each project extends the kernel without forking it

ExPhil proved that code beats prose for philosophical rigor. Existence Lang proves that a shared formal ontology beats ad-hoc prompting for human-agent collaboration.

### What Existence Lang has that ExPhil doesn't

- **Ontology graph** — nodes link to nodes, the graph IS the structure (not flat Python modules)
- **Ring-based scoping** — progressive disclosure from universal → domain-specific
- **Agent integration** — CLAUDE.md domain overlays consumed directly by AI agents
- **Axiology built in** — every node has "what IS it" + "why does it MATTER" + "how do we KNOW it"
- **Living system** — nodes evolve with understanding, not frozen papers
