Design thread (2026-07-12) for a **RelayCell** conflating-relay primitive + algebra-typed backpressure across the lazily reactive-cell family. Two design docs authored (in `lazily-spec/docs/`, **uncommitted**, NOT yet in cell-model.md/reactive-graph.md):

- `src/lazily-spec/docs/relaycell-backpressure-analysis.md` — primary: reactive primitives (§4.0), 18-case backpressure matrix, merge algebra, primitives (RelayCell/MergePolicy/BackpressurePolicy/SpillStore/Transport/Inbox/Outbox), §8 phased plan.
- `src/lazily-spec/docs/version-based-invalidation-plan.md` — separate optional per-Context revision-invalidation engine (salsa-style global revision + verified_at + value early-cutoff), unifying push/revision/TTL via `version()`.

**Measured fact:** `QueueCell` op costs ~327ns/616B/7allocs vs ~10ns bare `VecDequeStorage` — the reactive shell is charged even with zero subscribers. Go channels: ~23ns buffered send/recv. Benchmarked in lazily-go (scratch test, removed).

**Six non-negotiable invariants:** (1) converged state is binding/mechanism-independent when merge ⊕ is associative; (2) associativity = irreducible core, commutativity (reorder-safe) + idempotency (dup/replay-safe) = independent transport branches, full CRDT = all three, `Cell ≡ MergeCell<KeepLatest>`; (3) RelayCell ≠ QueueCell (distinct types, RelayCell = MergeCell hot-head + derived Slots + Effect + policy/spill); (4) `Signal` RETIRED → `Slot.eager` (consumer-gated, self-determined, pulls ancestors not descendants) — don't repurpose "Signal" (split meaning: FRP value vs Qt/OS/pubsub event); (5) `Reactive<T>` read supertype + `Source<T>` adds set/merge; reader-kind impl by ownership (owned→Slot+generation, actor→push-fed MergeCell carrying value in op msg, foreign→TTL Slot lazy / poll eager); (6) revision engine is per-Context opt-in, identical observable semantics, push stays default.

**Key derived insights:** `peek` removed from required QueueStorage contract (optional capability like capacity/is_full; head not in normative MUST-set) → raw channels conform directly; channel is a Transport not a Storage; merge cost law (none/lazy/active tiers; burst-merges pay dirty-once); Inbox/Outbox = directional RelayCell roles, a network link is Outbox→Transport→Inbox with backpressure chaining through.

**Start point = Phase 0** (spike lazily-rs, prove determinism in stackless lazily-js, port): (a) reader-kinds Cell→Slot + generation cell; (b) store-without-cascade on Cell/MergeCell; (c) remove peek from required contract. Full paste-ready goal prompt was written at session end. Discipline: distinct types, conformance parity per tier, formal pins (RelayCell.lean generalizing `coalesce_by_join_sound`; `RevisionEngine.get_equiv_push`). RelayCell subsumes existing `DurableOutbox.coalesce_to_snapshot` + TopicCell per-sub policy + op-log fusion.
