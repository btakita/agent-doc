lazily-kt releases via `.github/workflows/release.yml` on any `v*` tag → `./gradlew publish` to **GitHub Packages Maven** (`io.github.lazily:lazily`). GitHub Packages Maven versions are **immutable**: republishing an existing version fails the whole run with `409 Conflict` on the `.jar` PUT.

`build.gradle.kts` `version` can sit **ahead of the latest git tag** (a prior session bumps it, sometimes after already running a publish). So the dev version being `0.14.0` does NOT mean `0.14.0` is unpublished.

Before tagging a lazily-kt release, verify the version is free:
`gh api /orgs/lazily-hub/packages/maven/io.github.lazily.lazily/versions --jq '.[].name'`
If it already lists your version, bump `build.gradle.kts` + README `v…` line to the next version, commit, then tag. If you already pushed a bad tag, delete it: `git push origin :refs/tags/vX.Y.Z`.

**lazily-kt CI: FIXED green 2026-07-11** (commit 6154115).
