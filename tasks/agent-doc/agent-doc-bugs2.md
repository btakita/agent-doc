**What was actually wrong.** `decide_owner_claim` asked a clock — `owner.is_active_at(now)` — and never asked whether the incumbent's claim still belonged to the open turn. An owner claimed during turn N kept blocking turn N+1 for its full lease even though the turn advancing made it moot *instantly*. The lease was standing in for a fact the system already had. **Release is now derived, and asks in order of certainty.** `CloseoutOwnerProjection::release_reason`:

1. `SupersededByNewTurn` — the owner's `cycle_id` isn't the open turn's. No clock involved. This is the branch that makes the timeout unreachable in the case that kept firing.
2. `OwnerProcessGone` — typed liveness evidence from the caller.
3. `LeaseExpired` — the stopgap, and the only branch that reads a clock.

`decide_owner_claim` goes through it, so supersession answers before the clock ever gets a turn.

**Cancelling old settlements is now a data dependency.** `agent-doc-state-backbone/src/closeout_gate.rs` embeds this in the lazily graph in the `RetainedWriteSettlement` idiom — `Source`s for open cycle / owner / liveness / now, one `Computed<CloseoutGate>` over them. Writing a new open cycle **is** the cancellation. There is no `cancel_previous_settlement()` for anyone to forget to call, which was the point: every bug in this family has been a step someone had to remember.

The clock is an observation (`observe_now`) rather than an ambient read inside the derivation, so the whole gate is a pure function of its inputs and the expiry branch is testable without waiting for real time.

**The timeout is feedback.** It stays — a live same-turn owner really can wedge and something must eventually free it — but it is the last branch and `is_stopgap()` marks it. The one `Effect` in the module *reports* the stopgap firing; it does not perform the release, because the release is the `Computed` (`#idlerevisionreactive`: an Effect whose whole body assigns a value should have been a Computed). `run_closeout_owner_claim` logs `closeout_owner_released_by_stopgap`, so if a lease ever is what frees a claim in production, that is a visible signal that a supersession path is missing rather than something silently absorbed.

That inverts the relationship you asked about: the clock no longer decides anything, it only tells us when the derivation failed to.
